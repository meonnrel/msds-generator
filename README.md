# MSDS Generator

A simple web app that generates formatted pre-lab Material Safety Data Sheets (MSDS) using chemical data from the NCBI PubChem database. Built for pre-lab crammers to quickly look up formulas, physical properties, hazards, and export formatted tables directly to Word (.docx) or CSV.

## Deployment

Since it's 100% static, you can host it for free on GitHub Pages:
1. Push this repo to GitHub.
2. Go to **Settings** -> **Pages** -> Select **`main`** branch -> **Save**.
